# JagX UI screen map (PC + Mobile)

Concept images are generated in product design; runtime uses framebuffer compositor.

## Shared

1. **Boot** — logo + progress
2. **Lock / Auth** — PIN dots, fingerprint, face
3. **Shutdown** — red progress, “Shutting down”
4. **Restart** — purple cycle progress
5. **Home / Desktop** — windows or app grid
6. **Control Center** — Wi‑Fi, Hotspot, Data, Torch, Shot, Record
7. **Settings** — Network, Display, Sound, Security, Apps, About
8. **Contacts** — list + save numbers
9. **Dialer** — keypad + call
10. **Messages** — SMS threads
11. **Noder** — code editor
12. **Gallery / Files / Sheet / Base**

## PC-specific

- Multi-window desktop, Noder large, taskbar-style status

## Mobile-specific

- Full-screen apps, notification shade, lock biometrics prominence
