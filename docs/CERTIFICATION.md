# JagX Certification & readiness checklist

## Reality

A full national certification (security, accessibility, procurement) takes **months**, not 2 days. Use this checklist to track progress.

## Levels

### L0 — Lab demo (current target)
- [x] Boots under QEMU
- [x] Office apps present
- [x] Bilingual string table
- [x] Driver framework
- [ ] Signed release ISO per ministry lab

### L1 — Restricted pilot
- [ ] Hardware allow-list tested
- [ ] Offline policy documented
- [ ] User training completed (TRAINING.md)
- [ ] Incident response contact named
- [ ] No connection to national ID / payroll

### L2 — Department production
- [ ] Storage encryption on by default
- [ ] Verified boot on target machines
- [ ] Accessibility review
- [ ] Local language QA sign-off
- [ ] Vendor support contract (if any)

### L3 — Scale
- [ ] Multi-site deployment tooling
- [ ] OTA / update channel
- [ ] Independent security audit
- [ ] Procurement compliance (country-specific)

## Nigeria / Africa notes

- Prefer **pilot ministries** with strong IT units first
- Keep **English + local language** UI
- Do not claim NDPR / data-protection compliance until legal review
