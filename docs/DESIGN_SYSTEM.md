# JagX Design System

This document captures the visual direction we are building toward.

## Core Visual Language

- **Base**: Deep dark / near-black backgrounds (OLED friendly)
- **Primary Accent**: Electric teal / cyan
- **Secondary Accent**: Soft purple / violet
- **Typography**: Clean modern sans-serif, excellent readability
- **Shapes**: Soft rounded corners, gentle glass / depth effects
- **Motion**: Fast, interruptible, purposeful (especially on mobile)

## Goals

- Look premium and original (not a copy of existing OSes)
- Feel extremely fast and responsive
- Work beautifully on both large desktop displays and mobile screens
- Support light mode later, but dark is the primary experience

## Key Screens Direction (from concepts)

- Bootscreen: Minimal logo + elegant progress
- Mobile Home: Clean status, greeting, core apps, quick glance widgets, soft dock
- Desktop: Floating windows, modern top bar + dock, strong depth
- Settings: Clear grouped lists with icons and status
- Multitasking: Card-based app switcher with previews
- Notifications: Glass panels + quick toggles

These concepts guide the compositor, toolkit, and system apps as they are built.
