# JagX Mobile UX Principles

These principles guide every interface decision.

### 1. Instant Response
Every touch should produce visible feedback within one or two frames.  
Animations must be interruptible.

### 2. Clarity Over Density
Prefer clear hierarchy and readable typography over packing maximum information.

### 3. Consistency
The same gestures and patterns work across the system.  
Users should rarely have to re-learn.

### 4. Forgiveness
Easy undo, clear confirmation for destructive actions, and graceful error recovery.

### 5. Respect for Attention
Notifications are purposeful.  
No dark patterns, no forced engagement.

### 6. One-Handed Friendliness
Primary actions reachable with the thumb on typical phone sizes.

### 7. Accessibility Built-In
High contrast, scalable text, screen reader support, and motor accessibility from the beginning — not bolted on later.

### 8. Delight Without Waste
Motion and visual polish are welcome when they improve understanding or feel, never when they waste battery or cause jank.
