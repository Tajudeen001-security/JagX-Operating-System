# JagBrowser

JagBrowser is the **native web browser** for the JagX operating system.

It will **not** be a port of Chromium, Firefox, or WebKit.  
It is intended to be written specifically for JagX (once the OS has a usable graphics and networking stack).

### Planned features (long term)
- HTML / CSS rendering engine (start simple)
- JavaScript engine (or embed a small one initially)
- Secure sandboxing using JagX capabilities
- Fast and lightweight by design

This directory is currently a placeholder. Real work begins after the kernel and basic graphics/networking are ready.
