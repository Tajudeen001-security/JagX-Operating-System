Interface and loopback concept only.

## Planned Path

1. Network interface abstraction
2. Simple loopback
3. Basic Ethernet / virtio-net driver (QEMU)
4. ARP + IPv4 + UDP/TCP stubs
5. Socket-like API for JagBrowser and apps
